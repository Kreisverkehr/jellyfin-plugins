# Jellyfin Plugins

A collection of my plugins for [Jellyfin](https://jellyfin.org/).

## Available plugins

Plugins published through this repository can be installed directly from the Jellyfin Dashboard.

## Installation

1. Open the Jellyfin Dashboard.
2. Navigate to **Plugins → Repositories**.
3. Add a new repository with the following details:

   - **Repository name:** Kreisverkehr Jellyfin Plugins
   - **Repository URL:** `https://raw.githubusercontent.com/kreisverkehr/jellyfin-plugins/main/manifest.json`

4. Save the repository configuration.
5. Open the plugin catalog, select a plugin, and install it.
6. Restart Jellyfin if required.

## Compatibility

Plugin compatibility depends on the Jellyfin server version and the target API version of each plugin. Check the individual plugin descriptions and release notes before installation.
